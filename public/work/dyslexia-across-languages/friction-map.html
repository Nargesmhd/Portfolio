"Do we have the meeting tomorrow at 5?" Mixed-script text is normal in bilingual chats. Nothing breaks yet.

What happens
Everyday Farsi omits short vowels. The reader reconstructs each word from consonants and context.
Why it's worse
That reconstruction is letter-by-letter decoding, the process dyslexia disrupts most.
Evidence
SVowel-free Persian behaves as an opaque script; readers rely on sub-lexical decoding. Pouretemad et al., 2011
Fix to test
Optional vowel-mark display in reading mode.
What happens
The user must decide the language before the first letter. Forget, and the word comes out in the wrong script and has to be deleted.
Evidence
HWidely reported by bilingual users; no peer-reviewed study measures it, and none for dyslexic users.
Fix to test
Detect language from the first two words and switch silently.
salam → salad   khoobi → hobby   merci → mercy
What happens
Many people write Farsi in Latin letters. English autocorrect treats every one as a typo.
Why it's worse
A dyslexic writer already doubts their spelling. The replacement looks about as plausible as what they typed, so it slips through.
Evidence
SAdults with dyslexia make more spelling errors in a second language and type less accurately with more visual checking. Annals of Dyslexia, 2025; Reading and Writing, 2025
Fix to test
Autocorrect that follows the active-language signal and never replaces a word it has never seen.
What happens
Predictions come from all languages at once, or from the wrong one. The user reads three suggestions to find none that fit.
Evidence
HReported by multilingual users; not studied. SDyslexic error patterns differ by language, so a single mixed model would need per-language error data. Language Resources and Evaluation, 2022
Fix to test
One shared active-language signal for keyboard, autocorrect and predictions.
see you فردا at 5
What happens
Farsi runs right-to-left inside a left-to-right sentence. Deleting or inserting near the boundary moves the cursor somewhere unexpected.
Evidence
HKnown bidirectional-text behaviour; its cost for dyslexic users is unmeasured.
Fix to test
Visible direction boundary and a cursor that stays where the finger is.
yǐ → 己   已   巳
What happens
Typing the sound is easy. Choosing the character from a row of same-sound options is a visual task.
Why it's worse
Chinese dyslexia involves visual processing of character shape. The picker shows shape only.
Evidence
SSiok, Perfetti, Jin & Tan, Nature, 2004; PNAS pinyin study; Frontiers in Psychology, 2017
Fix to test
Meaning hints or a short context preview next to each character.
What happens
The user proofreads Farsi without vowels, English that autocorrect touched, and a Chinese character chosen by shape. Each needs a different check.
Why it's worse
Adults with dyslexia rely more on visual monitoring while writing. Here it has to run three ways at once.
Evidence
SReading and Writing, 2025 SEarly bilingual reading changes how dyslexia shows in adults. Scientific Studies of Reading, 2018
Fix to test
Accessibility settings per language, so each script gets its own support.
What happens
The message goes. Or, after enough friction, the user switches to voice. That workaround is a hypothesis worth testing first.
Evidence
HNo study has asked bilingual adults with dyslexia what they do on their phones.
